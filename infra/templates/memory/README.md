# Память Claude

Приватный репозиторий: контекст и журнал Claude Code на VM владельца. Подключается на VM в `/home/claude/github/memory` командой `claude-connect-memory`.

## Структура

```
README.md                этот файл: правила и протокол
notes/                   общее для всех VM: решения, заметки, итоги обсуждений
hosts/<имя VM>/          одна машина
  JOURNAL.md             журнал: что сделано, когда и зачем (новые записи сверху)
```

Claude Code на VM пишет только в свою папку `hosts/<имя VM>/` и в `notes/`, чужие `hosts/` не трогает. Так несколько VM не конфликтуют.

## Кто и как сюда подключается

| Кто | Как | Права |
|---|---|---|
| Claude Code на VM (пользователь `claude`) | SSH, свой ключ на этот репозиторий | чтение и запись |
| Владелец | напрямую | всё |

Записи в журнале не удаляются и не правятся задним числом.
